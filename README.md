# Notícias Cidade

Portal de notícias fictício desenvolvido como projeto de estudo de **HTML5** e **CSS3**, simulando a estrutura de um site jornalístico com múltiplas editorias, coluna de destaques e área de entrevistas.

## Sobre o projeto

O **Notícias Cidade** reproduz o layout típico de um portal de notícias, com cabeçalho de navegação, colunas laterais e conteúdo central dinâmico distribuído entre diferentes categorias de reportagem. O foco do projeto é a prática de organização de layout, semântica HTML e estilização com CSS puro, sem uso de frameworks ou bibliotecas externas.

## Funcionalidades

- **Navegação por editorias**: Home, Brasil, Internacional, Mundo, Economia, Saúde e Ciência
- **Coluna de entrevistas** com links para matérias completas em cada página
- **Formulário de cadastro** para notificações por e-mail (front-end)
- **Bloco de destaque** com notícia em evidência
- **Lista de notícias recentes** com imagem, título e resumo
- **Layout responsivo** dividido em três colunas (lateral, central e direita)

## Estrutura do projeto

```
noticias-cidade/
├── index.html          # Página inicial
├── brasil.html         # Editoria: Brasil
├── internacional.html  # Editoria: Internacional
├── mundo.html           # Editoria: Mundo
├── economia.html        # Editoria: Economia
├── saude.html            # Editoria: Saúde
├── ciencia.html          # Editoria: Ciência
├── style.css            # Estilização geral do site
└── imagens/              # Imagens utilizadas nas matérias
```

## Como executar

Por se tratar de um projeto estático (HTML + CSS), não é necessário instalar dependências.

1. Clone o repositório
   ```bash
   git clone https://github.com/PedroLins04/noticias-cidade.git
   ```
2. Acesse a pasta do projeto
   ```bash
   cd noticias-cidade
   ```
3. Abra o arquivo `index.html` diretamente no navegador, ou utilize uma extensão como o **Live Server** (VS Code) para melhor experiência de desenvolvimento.

##  Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização, layout em colunas e responsividade
